# disk-mosaic-gui

The graphical user interface for Disk Mosaic, built with the `egui` framework.
This is a library used for Graphical User Interface of https://crates.io/crates/Disk-Mosaic

## Features

- **Treemap Visualization**: Interactive graphical representation of disk space usage.
- **Intuitive Navigation**: Explore your folders via a smooth graphical interface.
- **Cross-platform**: Works on Windows, macOS, and Linux thanks to `eframe`.
- **Storage Management**: Dedicated panels to manage scans and settings.

## Key Dependencies

- `egui` / `eframe`: Immediate mode UI framework.
- `disk-mosaic-core`: Business logic and scanning engine.

## How to use

This crate can be launched via the main workspace binary with the `gui` flag.
